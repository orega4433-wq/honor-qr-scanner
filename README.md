# HONOR QR Scanner

Standalone QR scanner with home-screen launcher. This is NOT the built-in HONOR WLAN QR scanner. Uses ZXing and does not need an HONOR account. Shows scanned text and allows copying or opening web links.

Build: GitHub Actions -> Build APK -> artifact `honor-qr-scanner-debug-apk` (ZIP containing app-debug.apk). Debug builds may have different signing keys between runs.

For Microsoft Phone Link pairing, scan QR codes inside Link to Windows, not a generic QR reader.
